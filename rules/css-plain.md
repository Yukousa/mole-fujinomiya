# CSS：素の CSS

ビルドなし。`css/` のファイルを直接編集する。

## ファイル構成（読み込み順は固定）

| ファイル | 役割 |
|---|---|
| `variables.css` | トークン定義（`:root`）。**必ず先頭。** 後ろだと `var()` が解決できない |
| `reset.css` | リセット。編集しない |
| `base.css` | 全体の基本スタイル |
| `style.css` | メインのスタイル |

ファイルを追加する場合は `index.html` の `<link>` 追加も必要。

## トークン

- `variables.css` の `--*` を参照する
- この案件だけで使う追加トークンは `style.css` 先頭の `:root` に置く

## px の書き方

カンプの px は 16 で割って rem で書き、元の px をコメントで残す。

```css
.p-hero__title {
  margin-bottom: 1.5rem; /* 24px */
}
```

rem で書かないと、`base.css` の vw スケーリングで文字だけが伸縮し、幅や余白が追従しない。
`border` の 1px や `letter-spacing`（em で書く）など、rem にしない値はそのまま書く。

## ブレークポイント

`variables.css` 末尾のコメントに値を控えてある。

CSS カスタムプロパティはメディアクエリの条件式に使えないため、値は各メディアクエリに直接書く。

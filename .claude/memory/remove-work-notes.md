制作中のメモはコードに書かない。「〇〇待ち」「確認中」「仮の理由」などの状況や、制作上の注意（例：CSS は scss からビルドしたもの、直接編集しない）は、リポジトリ直下の `作業メモ.md` にまとめる（依頼者の指示 2026-10-14。CLAUDE.md「制作メモはコードに書かない」に追記済み）。

**Why:** 納品後の扱いは先方が決めるので、制作者向けの説明や社内の事情を納品物に残さない。ソースを見た先方の目にも触れる。
**How to apply:**
- 納品ファイル（HTML・JS・css/style.css）に書いてよいのは、構造を示す本来のコメントだけ（セクションの区切り「<!-- お知らせ -->」、head の「Google Fonts」「OGP」「favicon」、JS の関数の役割）。制作メモ（状況・ビルドの注意・実装の理由）は書かない
- 納品しないファイル（scss/ など）には実装の理由の説明を書いてよい（依頼者 2026-10-14）。Sass は // で書く（/* */ は CSS に出力される）
- 例外：段階提出の HIDDEN: コメントと、トークンの // 仮 の目印（どちらも納品前に消える）
- 新しく仮の実装や確認事項が出たら、その場で 作業メモ.md に追記する。回答が来て解決したら 作業メモ.md から消す
- 2026-10-14 に整理済み：HTML の制作メモを削除し、セクションの区切りと head の見出しコメントを付け直した。JS は関数の役割のコメントだけ残した。_reset.scss は出典と区切りの見出しだけ /* */、ほかは //
